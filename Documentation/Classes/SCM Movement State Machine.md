
A class derived from `SSM_StateMachine`, that is provided by *Scarlet State Machines* plugin ([https://github.com/Akarfire/Scarlet-StateMachines](https://github.com/Akarfire/Scarlet-StateMachines)).

This class is a base for all *Movement Layers* - movement state machines that take part in [Layered State Machine Architecture](../Layered%20State%20Machine%20Architecture.md). *Layers* contain [SCM Movement State Base](SCM%20Movement%20State%20Base.md)-type states, that represent different movement modes.
